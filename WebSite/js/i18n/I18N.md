# Site i18n

## Lingue pubbliche

Nel selettore del sito sono attive **tutte** le lingue in `SUPPORTED` (`vc-i18n.js`):

- **Italiano** — master, scritto a mano (`js/vc-i18n.js`, `vc-i18n-pages.js`, `vc-i18n-pages-extra.js`)
- **English** — secondo master, scritto a mano negli stessi file
- **Altre** — pack auto in `js/i18n/locales/*.json` (bundle `vc-i18n-locales.js`), qualità variabile

Fallback lookup runtime: lingua corrente → `it`.

Prefisso URL `/en/…` (e altre lingue): nginx rewrite interno + cookie `vc_site_lang`; OG/embed tradotti server-side via `sub_filter` (`og-meta.json` → maps/filters nginx).

## Workflow

1. Modifica le chiavi IT (e EN se serve) nei file `vc-i18n*.js`.
2. Opzionale — aggiornare il gap-fill EN da extract:

```bash
npm run i18n:extract
npm run i18n:bundle
```

`i18n:bundle` carica solo **EN** come gap-fill (`source: "auto"`): non sovrascrive le stringhe EN già presenti a mano.

`npm run i18n:generate` (Google gtx) è legacy e non va usato per copy pubblica.
