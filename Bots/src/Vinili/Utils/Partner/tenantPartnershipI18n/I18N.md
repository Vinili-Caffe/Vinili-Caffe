# Tenant partnership i18n

**Master language: Italian only.** Edit IT strings in:

- `packs.js` (`UI_IT`, `BADGE_IT`, `OBJECTIVE_IT`)
- `adminPacks.js` (`ADMIN_IT`)
- other `*UiPacks.js` / help packs that define IT

Then regenerate the 19 other languages (en + 18):

```bash
node Vinili/Utils/Partner/tenantPartnershipI18n/scripts/generate-tenant-i18n.cjs
```

Options: `--lang=en`, `--force`, `--concurrency=2`, `--langs=2`, `--delay=50`.

Output: `generated/ui|badges|objectives/*.json` (committed). Runtime merge: `applyGeneratedPacks.js`. Lookup fallback: `lang → it`.

Do not hand-edit generated files.
